Fraud Detection Using Machine Learning

 About the Project

This is my second Data Science internship project at DecodeLabs. In this project, I worked on a fraud detection system to identify fraudulent transactions using machine learning.

While working on this project, I learned how to handle an imbalanced dataset, prepare data for training, and evaluate classification models.

 What I Worked On

- Checked the dataset and explored its columns.
- Handled missing values using suitable imputation methods.
- Separated the input features and target column.
- Split the data into training and testing sets.
- Used SMOTE to handle class imbalance.
- Trained Logistic Regression and Random Forest models.
- Evaluated the models using Precision, Recall, F1-score, and ROC-AUC.
- Used a confusion matrix and ROC curve to understand model performance.
- Practiced hyperparameter tuning to improve the Random Forest model.

 Dataset

The dataset contains transaction-related information, and the target column is `is_fraud`.

- "0" represents a non-fraudulent transaction.
- "1" represents a fraudulent transaction.

 Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Imbalanced-learn
- Jupyter Notebook

 What I Learned

This project helped me understand that building a machine learning model is not just about training it. Data preparation, handling class imbalance, and selecting the right evaluation metrics are also important.

I also learned why accuracy alone may not be enough for fraud detection and why Precision and Recall are useful for understanding model performance.

Conclusion

This project was a good learning experience for me. I got practical experience with classification algorithms and learned more about evaluating machine learning models on imbalanced datasets.

I am continuing to improve my data science and machine learning skills by working on practical projects.
